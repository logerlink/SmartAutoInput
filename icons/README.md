# 插件图标说明

## 图标规格要求

Chrome扩展需要以下尺寸的图标：

- **16x16像素** - 工具栏小图标
- **48x48像素** - 扩展管理页面图标  
- **128x128像素** - 应用商店和安装页面图标

## 图标设计建议

建议使用简洁的设计，包含以下元素：
- 📝 表单图标（表示数据填充）
- 🧠 智能图标（表示智能识别）
- 🔄 重复图标（表示重复填充功能）

## 颜色方案

推荐使用以下颜色：
- 主色：#4CAF50（绿色，表示成功/完成）
- 辅色：#2196F3（蓝色，表示智能/技术）
- 背景：白色或透明背景

## 替代方案

如果暂时没有设计图标，可以使用以下替代方案：
1. 使用简单的文字图标："📝"
2. 使用纯色背景加字母："SF"（Smart Filler）
3. 使用在线图标生成器生成基础图标

## 图标文件命名

请将图标文件命名为：
- `icon16.png` - 16x16像素
- `icon48.png` - 48x48像素  
- `icon128.png` - 128x128像素
